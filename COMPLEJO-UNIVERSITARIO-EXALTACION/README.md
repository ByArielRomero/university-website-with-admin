# Sitio Web Estático - Complejo Universitario Exaltación de la Cruz

Este es una versión completamente estática del sitio web, diseñada para ser visualizada directamente en el navegador sin necesidad de servidores (Node.js, React, etc.).

## Cómo usarlo

Simplemente haz doble clic en el archivo `index.html` para abrirlo en tu navegador web favorito (Chrome, Firefox, Edge, Safari).

## Estructura de archivos

- `index.html`: El archivo principal de la página. Contiene la estructura y el contenido.
- `styles.css`: Estilos adicionales y animaciones personalizadas.
- `script.js`: La lógica de la página (filtros, galerías, menús).
- `images/`: Carpeta con todas las imágenes y logos.

## Tecnologías usadas

- **HTML5**: Estructura semántica.
- **Tailwind CSS (CDN)**: Para los estilos y diseño responsivo, cargado directamente desde internet.
- **Vanilla JavaScript**: Para toda la interactividad (sin frameworks).
- **Lucide Icons**: Para los íconos, cargado desde internet.

## Notas

- Al usar librerías externas vía CDN (Tailwind y Lucide), se requiere conexión a internet la primera vez para cargar los estilos e íconos.
- No se requiere instalación de nmem, npm ni ningún comando de terminal.
